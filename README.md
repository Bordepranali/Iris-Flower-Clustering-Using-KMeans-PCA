# Iris Flower Clustering Using K-Means and PCA

## Project Overview
This project demonstrates unsupervised machine learning techniques using the Iris Flower Dataset.

## Objectives
- Apply K-Means Clustering with K=3.
- Use the Elbow Method to analyze the optimal number of clusters.
- Apply PCA for dimensionality reduction.
- Visualize clusters using scatter plots.
- Compare predicted clusters with actual Iris species.
- Save and load trained models using Joblib and Pickle.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Joblib
- Pickle
- Jupyter Notebook

## Dataset
Iris Dataset from Scikit-learn.

## Algorithms Used
1. K-Means Clustering
2. Principal Component Analysis (PCA)

## Evaluation
Adjusted Rand Index (ARI) is used to compare the predicted clusters with the actual species labels.

## Files Included
- Iris_Flower_Clustering.ipynb
- kmeans_model.pkl
- scaler.pkl
- pca_model.pkl
- kmeans_pickle.pkl

## Conclusion
The Iris dataset was clustered using K-Means, visualized using PCA, and the trained models were saved for future use.
